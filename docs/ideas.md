# Идеи на потом

## Провода, которые можно выдернуть

Записано 2026-10-11 со слов Ромы.

- Патч-корд или силовой кабель любого юнита можно схватить мышкой и вытянуть: тянешь — кабель
  выходит из порта, болтается и падает, у него своя физика (верёвка из сегментов, гравитация,
  затухание).
- Юнит без кабеля «отключается» для посетителя: гаснет дисплей, лампочки, пропадает статистика,
  VU-метр замирает. Видно, что юнит недоступен.
- Кабель можно взять и воткнуть обратно, юнит включается.
- Общий выключатель: кнопка на ИБП. Нажал — гаснет вся стойка, нажал ещё раз — всё загружается
  обратно (можно с анимацией загрузки по юнитам).
- Простор большой: звук щелчка разъёма, искры, «ИБП пищит», когда выдернули питание, и т. п.

Состояние хранить только у посетителя (localStorage), сайт для остальных не меняется.
С выключенным JS кабели не рисуются и ничего не отключается.

## Рисовалка гостевой для графических планшетов

Записано 2026-10-11 со слов Ромы.

- нажим пера (`PointerEvent.pressure`) меняет толщину линии;
- ластик: отдельная кнопка и обратный конец пера (`pointerType === 'pen'`, `buttons & 32`);
- отмена и повтор (Ctrl+Z / Ctrl+Shift+Z), история штрихов;
- больше цветов (палитра + выбор любого), размер кисти ползунком, заливка;
- холст крупнее и во весь экран на телефоне.

## Стена фандомов (стикеры)

Записано 2026-10-11 со слов Ромы, пример — «Моя стена» на zhn.su.

- отдельный юнит или страница: доска, на которой разбросаны PNG-стикеры (фандомы, вещи, которые нравятся);
- стикеры можно таскать мышкой и пальцем, масштаб доски (−/+), кнопка «центр»;
- список стикеров — в `content/` (файл, подпись, ссылка), картинки — в `assets/`;
- позиции посетителя — только у него (localStorage); раскладку по умолчанию задаёт Рома.
